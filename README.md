# Apatis Blues — Editorial Profile

> Independent Menswear, Artisanal Raw Denim & Tailored Eccentricity Archive.
> Personal profile and digital lookbook of **Dimas Rezza** ([@.apatisblues](https://www.tiktok.com/@.apatisblues) &bull; [#nyentrikwithblues](https://www.tiktok.com/tag/nyentrikwithblues)).

---

## Visual Direction & Philosophy

* **The Anatomy of Blues:** A deliberate stance rejecting fast-fashion microtrends (*Apatis*) coupled with deep dedication to heavyweight raw selvedge denim, wabash discharge prints, and organic patina (*Blues*).
* **Atmosphere:** Velvet Bordeaux Noir (`#0B0204` & `#140407`) with Warm Alabaster Ivory typography and Three.js ambient textile motion.
* **Curated Archives:** Interactive Runway Index & Magazine Spreads covering brand collaborations (Nappa Milano, NBDN, Blue States Denim, UNIQLO, The Denim Station, Jiniso, Next Prime, Kahf).
* **Official Runways:** JF3 Fashion Show 2024 (Bespoke Project), Limbro Harajuku’s Silver Couture, Kahforward 2024, Tema Indonesia di Kompas TV.
* **Selected Reels:** Curated high-performing TikTok styling reels with direct video access.

---

## Tech Stack

* **Framework:** React 18 + Vite
* **Styling:** Tailwind CSS with custom editorial typography (Cormorant Garamond, Plus Jakarta Sans, JetBrains Mono)
* **Smooth Inertial Scrolling:** Lenis
* **Ambient Motion:** Three.js custom fabric shader canvas
* **Notifications:** Sonner Toast system

---

## Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
